# povorot

Прошивка контроллера (STM32F103) бортоповоротного вездехода со складываемой рамой.

- **Бортовой поворот** — электромагнитными катушками, управление силой тока
  через ШИМ (TIM4) с профилем «рывок-удержание», тайминг от TIM1.
- **Складывание рамы** — гидронасос-дозатор, вращаемый электродвигателем через
  контроллер **VESC** (команды по CAN). Угол рамы измеряется аналоговым
  датчиком (канал АЦП 0).
- **Связь** — шина CAN (ведущий/ведомый узел), дискретные входы/выходы, АЦП.

## Архитектура

Логика построена вокруг центрального **автомата режимов движения**
(`control_fsm`). Код разнесён по модулям с чёткой ответственностью:

| Модуль | Файлы | Назначение |
|--------|-------|------------|
| BSP | `bsp.[ch]` | тактирование, GPIO, ADC+DMA, CAN, TIM1/TIM4, хэндлы, помощники |
| Config | `config.h` | калибровки, периоды ШИМ, обороты VESC, адресация CAN, тайминги |
| IO | `io.[ch]` | дискретные входы `comp[]` и реле `relay[]` |
| Inputs | `inputs.[ch]` | рычаги тормоза (антидребезг), селектор, переключатели |
| VESC | `vesc.[ch]` | мотор складывания рамы: расчёт и плавность оборотов, отправка |
| Steering | `steering.[ch]` | катушки бортового поворота (профиль тока на TIM1/TIM4) |
| CAN | `can_bus.[ch]` | отправка/приём кадров, периодическая рассылка состояния |
| FSM | `control_fsm.[ch]` | центральный автомат: входы → команды исполнителям |
| App | `main.c` | инициализация, главный цикл, диспетчер колбэков/прерываний |

### Автомат режимов (`control_fsm`)

```
                deadman не активен
      ┌──────────────► DRIVE_DISABLED (мотор складывания стоп)
      │
   [главный цикл] ──► по состоянию рычагов тормоза:
      ├─ оба отпущены ─► DRIVE_NEUTRAL     (движение прямо/дифференциал по углу)
      ├─ левый        ─► DRIVE_BORT_LEFT   (поворот влево + складывание влево)
      ├─ правый       ─► DRIVE_BORT_RIGHT  (поворот вправо + складывание вправо)
      └─ оба нажаты   ─► DRIVE_BRAKE_BOTH  (торможение + центрирование рамы)
```

Складывание рамы (VESC) и катушки поворота — исполнители, которыми автомат
управляет через `Vesc_GetErpm()`/`erpm` и `control` → `period_left/right`.

## Сборка

PlatformIO, плата `bluepill_f103c8`, framework `stm32cube`:

```
pio run            # сборка
pio run -t upload  # прошивка через ST-Link
```
